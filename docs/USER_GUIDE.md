# End-user guide

## Freight procurement

Start in **Freight Procurement → Opportunities** when a shipment needs capacity.

1. Create the opportunity with lane, dates, mode, weight, commodity, handling units, special capabilities, government relevance, and compliance requirements.
2. Review carrier matches and expand any score to see the exact reasons.
3. Shortlist qualified carriers. A carrier marked ineligible cannot be shortlisted until its blocking capability or compliance gap is resolved.
4. Generate RFQ text, copy it into the approved email system, then mark the RFQ sent.
5. Record each quote’s total rate, fuel, accessorials, transit time, expiration, contact, and notes.
6. Review the side-by-side recommendation. The recommendation is advisory; the user records the final award and rationale.
7. Export the procurement summary for the contract file or customer/program record.

Start each day in Command Center. Review the daily brief, then open critical exceptions in priority order. Check the evidence and confidence before accepting a recommendation. Create a task when work must cross teams; resolve or dismiss only after recording an outcome.

Use Forecasting to compare actual demand with the selected model and confidence band. Overrides are human decisions and should include a reason. Use Scorecards for recurring supplier and carrier reviews, not as a substitute for exception-level evidence.

For imports, preview the source, map columns, resolve required-field warnings, and save a mapping template. Partial import keeps valid rows and produces a rejected-row report.

Use thumbs up/down whenever a signal or summary is especially useful or misleading. This feedback is part of model and rule governance.
